# Julekalender

En digital julekalender laget med Node.js, Express, EJS og MongoDB.

## Status

skal at spørsmålene skal vises alle sammen
## Starte prosjektet

1. Kjør `npm install`.
2. Kopier `.env.example` til `.env` og sett opp miljøvariablene.
3. Pass på at MongoDB kjører.
4. Kjør `npm start`.
